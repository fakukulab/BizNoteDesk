### Description

BizNote는 비즈니스 현장에서 필요한 노트와 명함 정보를 한곳에서 관리할 수 있는 macOS용 업무 기록 앱입니다.

회의록, 업무일지, 전시회 기록 등 업무 상황에 맞는 템플릿으로 기록을 빠르게 작성하고, 명함 이미지를 인식해 연락처 정보를 정리할 수 있습니다. 필요한 정보는 카테고리와 태그로 분류하고, iCloud를 통해 같은 계정의 기기에서 데이터를 관리할 수 있습니다.

주요 기능:

- 업무 노트, 회의록, 전시회 기록 작성
- 명함 이미지 인식 및 연락처 정보 정리
- 카테고리와 태그 기반 분류
- iCloud 기반 데이터 동기화
- 캘린더와 미리알림 연동
- PDF 및 스프레드시트 형식 내보내기

BizNote는 반복되는 업무 기록을 간결하게 정리하고, 현장에서 얻은 사람과 일정 정보를 놓치지 않도록 돕습니다.

### Notes

**1.1.2 (13) 변경 및 확인 방법**

- 노트 목록에서 새 노트를 만들면 바로 편집할 수 있습니다. 비어 있는 새 노트도 기존 노트와 행 높이가 같습니다. 각 제목 옆에는 수정일이 표시되며, 생성일순 정렬에서는 생성일이 표시됩니다.
- 기존 노트를 다시 열면 읽기 상태입니다. 우측 상단 연필 버튼으로 제목, 날짜, 본문, 템플릿, 태그를 편집할 수 있습니다. 변경 내용은 자동 저장되며 체크 버튼으로 편집을 종료합니다.
- 명함 관리에서 이름, 회사, 직급 등 텍스트 입력 내용이 왼쪽에 정렬됩니다.
- 한국어 설정의 회의록에서 주소록 아이콘으로 참석자를 불러오면 이름을 성부터 표시합니다. 스캔한 명함을 연결한 뒤 다른 참석자에게 쓸 수 있는 명함이 없으면 해당 행의 명함 아이콘이 비활성화됩니다.
- 명함 사진 데이터용 CloudKit 운영 스키마를 배포했습니다. 같은 iCloud 계정으로 Mac과 iPad에서 사진 동기화 코드가 들어간 개발 빌드를 실행해 합성 명함 사진을 양방향으로 확인했습니다. iPhone·iPad의 App Store 버전에서도 사진 동기화를 사용하려면 해당 코드를 포함한 BizNote iOS 업데이트가 필요합니다.


BizNote는 업무 노트, 회의록, 전시회 기록, 명함 정보를 관리하는 macOS 생산성 앱입니다.

로그인은 필요하지 않습니다. iCloud 동기화 기능은 사용자의 Apple ID와 iCloud 설정을 사용합니다.

앱 권한 사용 목적:

- Camera: 명함을 촬영하고 텍스트를 인식하기 위해 사용합니다.
- Contacts: 검토한 명함 정보를 연락처에 저장하고 중복 여부를 확인하기 위해 사용합니다.
- Calendars: 행사와 업무일지의 주요 행사를 사용자가 선택한 캘린더에 추가하기 위해 사용합니다.
- Reminders: 업무 항목을 미리알림에 추가하기 위해 사용합니다.
- Location: 회의 장소를 지도에서 찾기 위해 사용합니다.
- User Selected Files: 사용자가 선택한 위치로 PDF 또는 스프레드시트 파일을 내보내기 위해 사용합니다.

## Build Upload

Sign in to the Apple Developer account for the project team in Xcode > Settings > Accounts before creating the signed archive.

Archive for App Store Connect:

```sh
xcodebuild archive \
    -project BizNoteMac.xcodeproj \
    -scheme BizNoteMac \
    -configuration Release \
    -destination 'generic/platform=macOS' \
    -archivePath build/BizNoteMac-AppStore.xcarchive \
    -allowProvisioningUpdates
```

Upload the archive to App Store Connect:

```sh
xcodebuild -exportArchive \
    -archivePath build/BizNoteMac-AppStore.xcarchive \
    -exportPath build/AppStoreConnect \
    -exportOptionsPlist Distribution/ExportOptions-AppStoreConnect.plist \
    -allowProvisioningUpdates
```

After upload, wait for App Store Connect processing to finish, then select the processed build in the `1.1.2` macOS version page. Verify the selected build is `13` before adding it for review.
