개요

BizNote Desk는 업무 노트, 회의록, 행사 노트, 명함 정보를 관리하는 macOS용 생산성 앱입니다. 앱은 별도의 계정 가입이나 로그인을 요구하지 않습니다.

앱에 저장되는 데이터

BizNote Desk는 사용자가 입력하거나 선택한 노트, 회의록, 행사 노트, 업무 항목, 후속 조치, 명함 정보, 명함 이미지, 첨부파일, 행사 정보, 태그, 사용자 설정, 위치 텍스트를 저장할 수 있습니다.

이 데이터는 사용자의 기기에 저장됩니다. 사용자가 iCloud 동기화 또는 백업을 켠 경우 Apple의 CloudKit 또는 iCloud 저장 공간을 통해 사용자의 개인 iCloud 계정에 동기화되거나 저장될 수 있습니다.

데이터 수집

개발자는 BizNote Desk 사용자 데이터를 수집하기 위한 별도 서버를 운영하지 않습니다.

개발자는 사용자의 노트, 명함 정보, 이미지, 첨부파일, iCloud 데이터에 접근할 수 없습니다.

추적 및 광고

BizNote Desk는 앱과 웹사이트를 넘나드는 사용자 추적을 하지 않습니다.

BizNote Desk는 타사 광고 SDK, 분석 SDK, 추적 SDK를 포함하지 않습니다.

권한 사용

카메라 권한은 사용자가 명함 패널에서 카메라 촬영을 선택한 경우 명함 이미지를 촬영하고 이 Mac에서 텍스트를 인식하기 위해 사용됩니다.

연락처 권한은 사용자가 선택한 경우 회의록 참석자와 행사 노트의 만난 사람 정보를 주소록에서 불러오고, 명함 OCR 결과의 중복 연락처를 확인하며, 검토한 명함 정보를 연락처 앱에 저장하기 위해 사용됩니다.

위치 권한은 사용자가 회의 장소 입력 과정에서 현재 위치 사용을 선택한 경우 회의 장소를 찾거나 현재 위치를 기록에 입력하기 위해 사용됩니다.

캘린더 권한은 사용자가 설정에서 Apple 앱 연동을 켠 경우 행사 일정을 사용자가 선택한 캘린더에 추가하기 위해 사용됩니다.

미리알림 권한은 사용자가 설정에서 Apple 앱 연동을 켠 경우 후속 조치와 업무 항목을 사용자가 선택한 미리알림 목록에 추가하기 위해 사용됩니다.

사용자 선택 파일 접근 권한은 사용자가 선택한 위치로 PDF 또는 스프레드시트 파일을 내보내거나 사용자가 선택한 첨부파일을 앱에 저장하기 위해 사용됩니다.

이미지와 첨부파일 저장

명함 이미지는 앱의 BusinessCards 저장 영역에 저장됩니다. iCloud 백업 설정이 켜져 있고 iCloud 컨테이너를 사용할 수 있는 경우 사용자의 iCloud 저장 공간에 저장될 수 있으며, 그렇지 않은 경우 사용자의 기기 내 Application Support 영역에 저장됩니다.

첨부파일과 행사 이미지는 사용자가 선택하거나 업로드한 경우에만 저장됩니다.

데이터 삭제

사용자는 앱 안에서 노트, 명함, 명함 이미지, 첨부파일, 행사 정보, 사용자 템플릿을 삭제할 수 있습니다.

앱을 삭제하면 기기에 저장된 로컬 앱 데이터가 제거됩니다. iCloud 동기화를 사용한 경우 동기화된 데이터는 Apple의 iCloud 데이터 처리 방식에 따라 사용자의 iCloud 계정에 남아 있을 수 있습니다.

Overview

BizNote Desk is a productivity app for macOS that helps users manage work notes, meeting minutes, event notes, and business card information. The app does not require account registration or login.

Data Stored in the App

BizNote Desk may store notes, meeting minutes, event notes, work items, follow-up actions, business card information, business card images, attachments, event information, tags, user settings, and location text that the user enters or selects.

This data is stored on the user's device. If the user enables iCloud sync or backup, the data may be synced or stored in the user's personal iCloud account through Apple's CloudKit or iCloud storage.

Data Collection

The developer does not operate a separate server to collect BizNote Desk user data.

The developer cannot access the user's notes, business card information, images, attachments, or iCloud data.

Tracking and Advertising

BizNote Desk does not track users across apps or websites.

BizNote Desk does not include third-party advertising SDKs, analytics SDKs, or tracking SDKs.

Permission Usage

Camera permission is used when the user chooses to capture a business card image from the business card panel, so the app can take the image and recognize text on this Mac.

Contacts permission is used when the user chooses to import meeting attendees or people met in event notes from Contacts, check duplicate contacts from business card OCR results, or save reviewed business card information to the Contacts app.

Location permission is used when the user chooses to use the current location while entering a meeting place, so the app can find the meeting place or enter the current location into the record.

Calendar permission is used when the user enables Apple app integration in Settings, so event schedules can be added to the calendar selected by the user.

Reminders permission is used when the user enables Apple app integration in Settings, so follow-up actions and work items can be added to the reminders list selected by the user.

User-selected file access is used to export PDF or spreadsheet files to a location selected by the user, or to save attachments selected by the user in the app.

Image and Attachment Storage

Business card images are stored in the app's BusinessCards storage area. If iCloud backup is enabled and the iCloud container is available, they may be stored in the user's iCloud storage. Otherwise, they are stored in the device's Application Support area.

Attachments and event images are stored only when the user selects or uploads them.

Data Deletion

Users can delete notes, business cards, business card images, attachments, event information, and custom templates inside the app.

Deleting the app removes locally stored app data from the device. If iCloud sync was used, synced data may remain in the user's iCloud account according to Apple's iCloud data handling.
