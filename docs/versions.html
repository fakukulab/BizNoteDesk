Release Notes

💻 배포 중인 버전Latest available 1.0.1macOS 15.0+
1.1.0심사 대기 중Waiting for Review
  • 노트, 명함, 행사 화면을 macOS 스타일로 정리하고, 노트와 행사 추가의 입력 항목을 구분선으로 나눴습니다.
  • 업무일지의 주요 행사를 캘린더와 연동할 수 있습니다. 진행 중·보류 업무는 다음 업무일지에 자동으로 복사되며, 같은 날의 회의록을 바로 열 수 있습니다.
  • 회의록과 행사 노트에 메시지 업무 분류를 추가했습니다. 온라인 회의록에는 통화 번호를 기록할 수 있습니다.
  • 노트 메모와 행사 소개·전시품목에 제목·본문, 취소선, 글머리 기호, 번호 목록 서식을 추가했습니다.
  • Refined the macOS interface for notes, business cards, and events, with dividers between fields in note and event entry forms.
  • Sync key work log events with Calendar, carry in-progress and on-hold tasks into the next work log, and open matching meeting minutes from the same day.
  • Use the Message task category in meeting minutes and event notes, and record a call number in online meeting minutes.
  • Format note memos, event introductions, and exhibit items with heading and body styles, strikethrough, bullets, and numbered lists.
